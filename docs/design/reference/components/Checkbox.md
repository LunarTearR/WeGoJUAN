# Checkbox

A checkbox row with a label and optional second line, used for picking days to Push.

- **Provide:** `label`, optional `description`, and checkbox attributes (`checked`, `onChange`, `disabled`).
- Rows stack with a hairline between them. Checked boxes fill `orange` with an `on-orange` tick and pop.
- In the Push panel the label is "{date} · ในทริป: {status} → ปฏิทิน: {status}" and the description is the private Reason or "วันที่ยืนยันของทริปนี้".
