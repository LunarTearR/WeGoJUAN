# Pill

A small rounded label for status and roles.

- **Provide:** `children` (one to four words), `tone`, optional `icon` (an Icon name) or `face` (a Face mood).
- Tones: `solid` (orange: ยืนยันแล้ว, ผู้จัด, ลงตัวที่สุด) · `orange` (soft tint: เห็นแค่คุณ) · `neutral` (กำลังหาวัน, แขก) · `free` / `busy` (a friend's status, with the face) · `honey` (waiting for a re-sync).
- Pills are read-only. Never make one look like a button.
