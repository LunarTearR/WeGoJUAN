# MonthNav

The month header for both calendars: previous, the Thai month and year, next.

- **Provide:** `year`, `month` (1–12), `onPrev` / `onNext` (leave one out to disable it, e.g. at the edge of a trip's Date Range), optional `title`.
- The title is formatted with `th-TH` ("ธันวาคม 2569") and announced politely when it changes.
