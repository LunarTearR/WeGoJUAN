# EmptyState

A big status icon, a short title, one friendly line and one action for a screen or list with nothing in it.

- **Provide:** `title`, `children` (the friendly line), optional `action` (a Button), `icon` (default `calendar`; use `finding` for "no match yet"), `size`.
- The title says what's missing plainly; the line underneath is where the personality lives. See Microcopy.
